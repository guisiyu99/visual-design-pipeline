# Visual Design Pipeline

A PRD-first, quality-gated AI design workflow and Codex Skill for turning product requirements into consistent prototypes, editable designs, and front-end pages.

**Pipeline:** PRD understanding → visual references → draft Design Spec → Stitch/Figma visual validation → approved design.md → production → review and reusable lessons.

Start with nothing but a PRD. The agent identifies flows and representative pages, proposes 2–3 visual directions, validates them before freezing design standards, and asks the user only for necessary decisions.

See [Chinese README](README.md), [Skill](SKILL.md), and [workflow](docs/工作流.md).

**V3 Beta:** Requires hands-on validation in real projects. External tools require actual connections and permissions.
