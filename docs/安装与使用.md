# 安装与使用

## 安装

```bash
git clone https://github.com/guisiyu99/visual-design-pipeline.git ~/.agents/skills/visual-design-pipeline
```

如果目录已经存在，请先检查本地修改，再决定更新方式。

## 从零开始

准备一份 PRD（文档、文本、路径或可访问链接），在 Codex 输入：

> 使用 $visual-design-pipeline。这是我的 PRD：[路径]。我没有设计稿或视觉参考。先梳理用户、主要流程和页面清单，再带我选视觉参考、提取 Design Spec、验证样板，最后产出 design.md。不要一开始生成整个前端站点。

## 用户需要做什么

阶段 0 核对关键产品理解；阶段 1 选择视觉方向；阶段 3 根据可见设计给反馈并确认；阶段 5 选择最终交付形式。其他工作应由 Agent 主动推进。

## 其他启动场景

- 有 Figma 参考：提供链接和 PRD，让 Agent 分开识别业务来源与视觉来源。
- 有 design.md：提供已有规范与新需求，检查后直接复用。
- 有页面要修：提供截图、代码或可访问预览，先诊断再改。
